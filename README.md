# VANTHEN — Streetwear Website

Komplette responsive Streetwear-Website für VANTHEN.

## Enthalten
- Responsive Startseite
- VANTHEN SVG-Logo + Favicon
- Drop 001 Produktkatalog
- Produktfilter und Produktsuche
- Produkt-Modal mit Größenwahl
- Warenkorb mit LocalStorage
- Versand-Hinweis ab 120 €
- Newsletter- und Kontaktbereich
- Mobile Navigation
- Datenschutz, Impressum und Versand-Seiten

## GitHub Pages
Veröffentliche den Branch `main` aus dem Ordner `/ (root)` unter **Settings → Pages**.

Danach ist die Seite unter dieser Adresse vorgesehen:

`https://romeo17567.github.io/vanthen-website/`

## Hinweis zum Checkout
Der aktuelle Checkout erzeugt nur eine E-Mail-Bestellanfrage. Für echte Kartenzahlungen muss später z. B. Stripe oder Shopify angebunden werden.

## Vor echtem Verkauf
Impressum, Datenschutz, Widerrufsbelehrung, Versandbedingungen und ggf. AGB müssen mit echten Betreiberangaben ergänzt und rechtlich geprüft werden.
