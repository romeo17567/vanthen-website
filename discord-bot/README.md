# VANTHEN Discord Community Bot

Persistent Discord bot for the VANTHEN community.

## Railway

Set the service root directory to `/discord-bot`.

Required variables:
- `BOT_TOKEN`
- `GUILD_ID`
- `WEBSITE_URL=https://romeo17567.github.io/vanthen-website/`

Start command:
`npm start`

Never commit `.env` or the Discord bot token.
